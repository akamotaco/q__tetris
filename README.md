# NEON TETRIS

neon 글래스무프 느낌의 웹 테트리스. 빌드 없이 **`index.html`을 더블클릭**하면 바로 실행됩니다.

![preview](docs/preview.png)
![mobile](docs/preview-mobile.png)

## 실행
- `index.html` 열기 (Chrome / Edge / Firefox / Safari 최신 버전)
- 또는 로컬 서버: `npx serve .`

## 조작
| 키 | 동작 |
| --- | --- |
| `←` `→` | 이동 (DAS 140ms / ARR 28ms 연속 이동) |
| `↓` | 소프트 드롭 (칸당 +1점) |
| `Space` | 하드 드롭 (칸당 +2점) |
| `↑` / `X` | 시계 방향 회전 |
| `Z` | 반시계 방향 회전 |
| `A` | 180° 회전 |
| `C` / `Shift` | 홀드 |
| `P` / `Esc` | 일시정지 |
| `R` | 재시작 |
| `M` | 소리 켜기/끄기 |

모바일/태블릿에서는 아래에 터치 버튼이 자동으로 나타납니다.

## 특징
- **SRS 회전 + 월킥** (I/JLSTZ 킥 테이블), 7-bag 랜덤, 홀드, 고스트 조각
- **T-스핀 판정** (3-corner 규칙 + 킥 만회 판정, MINI 구분)
- 가이드라인 스코어링: 싱글/더블/트리플/테트리스, T-스핀, B2B ×1.5, 콤보, 퍼펙트 클리어
- 락 딜레이 500ms(15회 리셋), 레벨별 중력 곡선, 최고 점수 저장(localStorage)
- 연출: 블록 글로우/비벨, 줄 삭제 플래시 + 파티클, 하드 드롭 트레일, 화면 흔들림,
  레벨업 플래시, 상단 위험 글로우, 팝업 텍스트, WebAudio 효과음(외부 파일 없음)
- 반응형: 데스크톱 3열 → 모바일은 보드 중심 레이아웃 + 터치 바

## 파일
| 파일 | 설명 |
| --- | --- |
| `index.html` | 마크업 |
| `style.css` | UI 테마 (반응형 포함) |
| `core.js` | 순수 로직: 조각/회전/킥/충돌/판정/스코어링 (Node에서 단테 가능) |
| `game.js` | 렌더링, 입력, 게임 루프, HUD, 연출 |
| `test.js` | 코어 로직 단위 테스트 — `node test.js` (77개 항목) |
| `probe.js` | 헤드리스 브라우저 통합 테스트 — `node probe.js` |

## 디버그 / 자동화
- `index.html?debug`로 열면 콘솔에서 `TetrisDebug`로 내부 상태(`G`), `spawn/move/rotate/hardDrop/lockPiece` 등을 직접 조작할 수 있습니다.
- `node probe.js`는 설치된 Chrome/Edge를 헤드리스로 띄워 다음을 검증합니다.
  - 런타임 예외·콘솔 에러 수집
  - 단위 통합 시나리오 22건(줄 삭제, 레벨업, T-스핀 더블, 홀드, 벽 제한, 게임 오버, DAS/ARR, 소프트 드롭 점수 …)
  - 휴리스틱 AI 자동 플레이(300조각)로 실전 삭제/점수 경로 확인
  - 캔버스 픽셀 샘플링으로 블록/고스트/프리뷰 실제 렌더링 확인, 모바일 폭 레이아웃 확인
